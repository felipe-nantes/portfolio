# Portfólio · Felipe Nantes

Site de portfólio pessoal — estudante de Engenharia de Software (Apucarana-PR).

Feito com **HTML5, CSS3 e JavaScript** puro, sem frameworks. Quatro páginas: início, projetos, sobre e contato.

## Recursos
- Layout responsivo (mobile, tablet, desktop)
- Menu de navegação com versão mobile (hamburger)
- Formulário de contato com validação via JavaScript
- Efeitos interativos: cursor glow, scroll reveal, texto digitado, filtro de projetos, barras de skill animadas
- SEO básico: meta tags, Open Graph, dados estruturados (Schema.org), HTML semântico

## Rodar localmente
```bash
python -m http.server 5500
# abrir http://localhost:5500
```
